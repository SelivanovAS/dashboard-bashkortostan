# Башкортостан: состояние внедрения на 11.09.2026

## Реализовано и проверено

- Реестр: 45 судов первой инстанции, Верховный Суд Республики Башкортостан,
  Шестой КСОЮ. Все 69 строк Excel сохранены, включая 23 судебных присутствия.
  Присутствия работают через подтверждённые общие серверы основных судов;
  отдельные дубли поиска для них не создаются.
- Первый сбор: по одной странице каждого из 46 открытых источников, без
  перехода на следующие страницы. Поиск Шестого КСОЮ закрыт проверочным кодом;
  оператор загружает выдачу, парсер проверяет уже известные карточки.
- Обе картотеки, архивы, кассационный импорт, повторная загрузка и отложенное
  объявление событий поддержаны. Чужие регионы и неоднозначные связки отсекаются.
- Апелляции связываются по суду и номеру; реальные совпадения номеров между
  Салаватом, Баймаком и Ишимбаем покрыты регрессионными проверками.
- Время Шестого КСОЮ учитывается как Самара, UTC+4, в интерфейсе, дайджесте
  и календаре. Суды Башкортостана используют UTC+5.
- Оператору и владельцу доступны все 47 источников для ручного добора истории.
  Индикатор регулярного ручного обновления относится только к закрытому поиску.
